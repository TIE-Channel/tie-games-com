Panorun

Seluruh level terlihat, teman-teman berlari di samping Anda.

Panorun adalah emulator untuk game konsol 8-bit klasik yang menjaga seluruh level tetap terlihat: semua yang sudah Anda lewati tetap ada di layar di sekitar game. Main bersama secara online, dan teman-teman Anda berlari di samping Anda di dalam game Anda sendiri. Panorun dibuat oleh TIE-Games, studio independen di Dresden, Jerman.

Punya ponsel Android? Bantu uji Panorun di Google Play.

Apa yang dilakukannya

  • Menjaga level tetap terlihat. Konsol menggambar satu layar sekaligus dan melupakan sisanya. Panorun menyimpan setiap layar yang digambar dan melukis level di sekitar game di tempat seharusnya, jadi tanah yang sudah Anda lewati tetap di layar di kiri, atas, dan bawah.
  • Menggambar peta saat Anda bermain. Sebuah strip di bawah game menampilkan level sejauh ini, dengan Anda di dalamnya.
  • Membuat Anda bisa main bersama. Buka ruang dan kirim kodenya, atau gabung ke salah satu ruang yang terdaftar di server ruang; siapa pun yang bergabung memainkan salinan game yang sama miliknya sendiri, dan karakter setiap orang berlari di game semua orang lain, masing-masing dengan warnanya, dengan garisnya di peta. Game yang jauh di depan menunggu yang lain, agar semua tetap bersama. Hingga dua belas pemain per ruang.
  • Mengobrol sambil bermain. Di dalam ruang, tahan tombol mikrofon (V di komputer) untuk bicara, atau ketuk agar tetap menyala. Suara game Anda dan kebisingan di sekitar disaring, jadi yang lain mendengar suara Anda, bukan game atau ruangan Anda.
  • Server ruang, atau tanpa server. MAIN ONLINE membuka ruang di server ruang Panorun di web, terdaftar di sana agar teman-teman Anda bisa bergabung. Atau main LOKAL: ruang berjalan di jendela orang yang membukanya, dan teman-teman bergabung langsung. Panorun untuk Windows dilengkapi server ruang yang bisa dijalankan siapa saja.
  • Pertarungan sungguhan. Begitu Panorun tahu di mana game menyimpan nyawa Anda, pemain lain bisa memukul karakter Anda, dan rasanya sakit seperti musuh dalam game: Anda terpental dan nyawa berkurang. Nyawa setiap orang tampil di atas namanya.
  • Mempelajari setiap game sendiri. Saat Anda bermain, Panorun mempelajari rupa karakter Anda dan tombol mana yang melompat atau memukul, dan pemain dalam satu ruang berbagi apa yang diketahui Panorun mereka tentang sebuah game.
  • Merekam permainan Anda. REKAM menyimpan setiap tombol yang Anda tekan, dan PUTAR ULANG memainkan lagi permainan itu dari awal.
  • Main dengan yang Anda punya. Keyboard atau gamepad, setiap tombol bisa Anda atur. Di ponsel, tombol arah di kiri dan A, B, TURBO A, dan TURBO B di kanan.
  • Lancar di ponsel. Prosesor serta chip gambar dan suara konsol berjalan sebagai kode native, jadi Panorun lancar di ponsel, bahkan dengan teman-teman di ruang.

Tidak ada game yang disertakan. Panorun memainkan game yang dibuat untuk konsol 8-bit klasik. Pengembang independen masih membuat game baru untuk konsol ini, dan banyak yang membagikannya gratis - cari 8-bit homebrew games di web. Atau gunakan salinan game milik Anda. Tambahkan dengan TAMBAH GAME, atau taruh di jendela; Panorun menyimpannya di Documents\Panorun. Di ponsel, TAMBAH GAME dan PILIH FOLDER membuka pemilih file ponsel Anda. Atau COBA DEMO: dua game kecil milik Panorun sendiri, perkelahian di atap gedung pada malam hari dan lari melintasi bukit hijau.

Privasi Anda

Panorun tidak punya akun, analitik, maupun iklan. Game, pengaturan, dan rekaman Anda tetap di komputer atau ponsel Anda. Panorun hanya menghubungi GitHub, untuk mencari versi yang lebih baru (di Windows); server ruang kami dan situs ini, untuk daftar game yang file game-nya sudah kami terbitkan, dan file game dalam daftar saat Anda memulainya; dan, saat Anda main online, server ruang atau komputer yang ruangnya Anda masuki: saat itu ia membagikan nama Anda, karakter Anda, nyawanya, dan level tempat Anda berada kepada pemain di ruang itu, dan server ruang atau komputer ruang melihat alamat internet Anda. Saat Anda menahan atau menyalakan tombol mikrofon di ruang, suara Anda dikirim langsung ke pemain di ruang itu; suara itu tidak direkam dan tidak disimpan di mana pun. Detailnya ada di Kebijakan Privasi (dalam bahasa Inggris).

Lisensi sumber terbuka

Panorun dibuat dengan perangkat lunak sumber terbuka: antara lain Python, pygame dan SDL, NumPy, serta Opus, RNNoise, dan speexdsp dari Xiph.Org untuk suara. Masing-masing digunakan di bawah lisensinya sendiri. Daftar lengkap, dengan teks setiap lisensi, ada di dalam Panorun (PENGATURAN → LISENSI), di samping program di Windows, dan di sini: pemberitahuan pihak ketiga.
